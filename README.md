# solove_math_answers

数学解答 PDF を管理するリポジトリです。

公開版の PDF:
https://github.com/ku-sakumon-circle/solove_math_answers/blob/main/pdf/00main.pdf

主な内容:

- `problems/`: 各問題の TeX 原稿
- `main/`: 全体 PDF を組むための TeX 一式
- `preamble/`: 共通プリアンブル
- `pdf/`: 生成済み PDF
- `mailbox/`: 元資料

このリポジトリは解答データと PDF 生成用ファイルのみを対象にしています。
