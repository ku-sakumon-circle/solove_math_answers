\begin{prob}{001}{}{2018年9月号 学コン3番}
 $xy$平面上の放物線$G: y=mx^2 + px + q^n$を考える. $G$と$x$軸は2つの交点をもつものとする. 各交点における$G$の接線2本と$x$軸で囲まれる部分の面積を$S$とするとき,
 \begin{enumerate}
  \item $S$を$m,n,p,q$で表せ.
  \item $m$を整数, $n$を自然数, $p,q$を素数とする. $S$が自然数となるとき,
  \begin{enumerate}
   \item $p$を求めよ.
   \item $S$を求めよ.
  \end{enumerate}
 \end{enumerate}
\end{prob}
