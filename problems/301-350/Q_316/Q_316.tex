
\begin{prob}{316}{\hosi 8}{OMCB074(E), 自作問題}
    複素数の組 $(a,b,c)$ は以下の連立方程式を満たします.
    \begin{align*}
        a + ab + ac + abc = 1\\
        b + bc + ba + abc = 2\\
        c + ca + cb + abc = 3
    \end{align*}
    このとき, 積$abc$としてありうる値の総和は互いに素な正の整数$p,q$を用いて$\frac{p}{q}$と表せるので, $p+q$の値を解答してください.
\end{prob}
